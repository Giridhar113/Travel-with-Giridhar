# Travel with Giridhar

**Release:** Travel Website v1.2

A polished frontend travel website built with HTML, CSS, and JavaScript. The project presents destinations, travel packages, services, company information, and a contact form in a responsive portfolio-ready layout.

## Release Goal

Make the website more functional, professional, and ready to show as a frontend project.

- Added destination search using JavaScript

- Improved button styling, spacing, hover effects, and card alignment
- Added smooth scrolling and stronger hero call-to-action buttons
- Added footer credit with Giridhar Reddy on all pages
- Added save destination functionality using localStorage
- Updated README documentation

## Pages

- `index.html` - Home page with hero slider, trust stats, featured trips, AI planner, trending trips, and review slider
- `destinations.html` - Destination cards with JavaScript search
- `packages.html` - Travel packages with duration, price, features, and booking buttons
- `emi.html` - EMI-friendly travel packages with monthly payment estimates
- `services.html` - Travel services using original local service images
- `blog.html` - Travel tips and planning guides
- `gallery.html` - Destination photo gallery
- `about.html` - Company story, mission, reasons to choose us, and developer profile
- `contact.html` - Booking form and contact form with JavaScript success alerts
- `404.html` - Branded not found page
